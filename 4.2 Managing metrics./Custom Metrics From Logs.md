Derive metric data from log entry content. Track specific messages or get latency data from the logs. Can then be used for alerting policies.

2 Types of logs metrics
1. System defined log-based metrics, calculated only from logs ingested by Logging.
2. User defined log-based metrics, made by you, count number of entries that match filter.
